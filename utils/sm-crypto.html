SM2 是国家密码管理局发布的椭圆曲线公钥密码算法（GM/T 0003-2012），安全性等同于 RSA-2048，但密钥更短、速度更快。
与 Java (BouncyCastle) 互通：加解密时选择「带 04 前缀」格式，签名时选择「DER 编码」格式即可无缝对接。

SM3 是国密杂凑算法（GM/T 0004-2012），输出 256 位摘要，安全性高于 MD5/SHA-1，等同于 SHA-256。
常用于：数据完整性校验、数字签名、消息认证码。

SM4 是国密分组密码算法（GM/T 0002-2012），密钥和分组长度均为 128 位，安全性等同于 AES-128。
与 Java (BouncyCastle) 互通：模式选 CBC，填充选 PKCS5，密钥/IV 均使用 Base64 格式，加密输出也选 Base64。
