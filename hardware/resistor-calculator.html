📚 核心知识点

1. 串联电路特性

串联电路中，所有电阻依次连接，电流只有一条路径。

R_total = R₁ + R₂ + R₃ + ... + Rₙ
  • 总电阻：各电阻之和，总电阻大于任何单个电阻
  • 总电流：I_total = I₁ = I₂ = I₃ = ...（处处相等）
  • 电压分配：V_total = V₁ + V₂ + V₃ + ...，电阻越大分压越大

2. 并联电路特性

并联电路中，各电阻两端连接到同一电压源，电流有多条路径。

1/R_total = 1/R₁ + 1/R₂ + 1/R₃ + ... + 1/Rₙ
  • 总电阻：小于任何单个电阻，并联电阻越多总电阻越小
  • 总电流：I_total = I₁ + I₂ + I₃ + ...（各支路电流之和）
  • 电压：V_total = V₁ = V₂ = V₃ = ...（各支路电压相等）

3. 两个电阻并联的快捷计算

当只有两个电阻并联时，可以使用更简洁的公式：

R_total = (R₁ × R₂) / (R₁ + R₂)

4. 电阻单位换算

1 kΩ = 1000 Ω
1 MΩ = 1000 kΩ = 1,000,000 Ω
1 mΩ = 0.001 Ω

5. 实际应用场景

  • 限流电阻：串联电阻限制电路电流，保护元件
  • 分压电路：串联两个电阻实现电压分配
  • 负载并联：多个用电器并联工作
  • 电阻匹配：通过串并联获得特定阻值
