📚 核心知识点

1. 欧姆定律

欧姆定律描述了电压、电流和电阻之间的关系。

V = I × R (电压 = 电流 × 电阻)
I = V / R (电流 = 电压 ÷ 电阻)
R = V / I (电阻 = 电压 ÷ 电流)
P = V × I (功率 = 电压 × 电流)

单位：电压 V (伏特)，电流 I (安培)，电阻 R (欧姆)，功率 P (瓦特)

2. 串联电路

串联电路中，所有元件依次连接，电流只有一条路径。

R_total = R₁ + R₂ + R₃ + ...
I_total = I₁ = I₂ = I₃ = ...
V_total = V₁ + V₂ + V₃ + ...
  • 总电阻：各电阻之和
  • 总电流：处处相等
  • 总电压：各元件电压降之和

3. 并联电路

并联电路中，各元件两端连接到同一电压源，电流有多条路径。

1/R_total = 1/R₁ + 1/R₂ + 1/R₃ + ...
I_total = I₁ + I₂ + I₃ + ...
V_total = V₁ = V₂ = V₃ = ...
  • 总电阻：小于任何单个电阻
  • 总电流：各支路电流之和
  • 总电压：各支路电压相等

4. 电阻单位换算

1 kΩ = 1000 Ω
1 MΩ = 1000 kΩ = 1,000,000 Ω
1 mΩ = 0.001 Ω

5. 功率计算

电路中的功率消耗可以用以下公式计算：

P = V × I
P = I² × R
P = V² / R

应用场景：计算电阻功率选型、电源容量估算、电池续航时间等。
